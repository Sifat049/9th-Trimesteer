\section{Introduction}


Sudoku is a classic constraint-based puzzle that can be modeled as a
Constraint Satisfaction Problem (CSP).

The objective of this project is to develop an Artificial Intelligence based
Sudoku solver that efficiently solves Sudoku puzzles using intelligent search
and constraint propagation techniques.

Instead of using a naive brute-force approach, this project implements CSP
representation, AC-3 (Arc Consistency-3), Backtracking Search, and Minimum
Remaining Values (MRV) heuristic.

The main goal is to reduce unnecessary search operations and improve solving
efficiency.



%---------------------------------------

\section{Problem Representation as CSP}


A Constraint Satisfaction Problem consists of three main components:

\subsection{Variables}


The Sudoku board contains 81 variables where each cell represents one
variable.


\[
Total\ Variables = 9 \times 9 = 81
\]


\subsection{Domains}


The domain represents possible values for each variable.

For an empty cell:

\[
Domain = \{1,2,3,4,5,6,7,8,9\}
\]


For a pre-filled cell:

\[
Domain = \{Given\ Value\}
\]



\subsection{Constraints}


Sudoku contains three main constraints:

\begin{itemize}

\item No duplicate number can exist in the same row.

\item No duplicate number can exist in the same column.

\item No duplicate number can exist inside the same 3x3 sub-grid.

\end{itemize}



%---------------------------------------

\section{Input and Output Specification}


The program reads Sudoku puzzles from:

\begin{verbatim}
puzzles.txt
\end{verbatim}


Each puzzle is represented as an 81-character string.

The first 9 characters represent the first row, the next 9 characters
represent the second row, and so on.


The digit 0 represents an empty cell.


After solving, the program generates:

\begin{verbatim}
solutions.txt
\end{verbatim}


The output file contains solved Sudoku boards represented as 81-character
strings without zero values.

\section{Algorithm Design}


\subsection{AC-3 Algorithm}


AC-3 (Arc Consistency-3) is used as a preprocessing algorithm before applying
search.

The purpose of AC-3 is to reduce variable domains by removing values that
cannot satisfy Sudoku constraints.


The algorithm checks every pair of connected variables called arcs:

\[
(X_i,X_j)
\]


If a value in one variable has no supporting value in another variable,
that value is removed from the domain.


\textbf{Advantages of AC-3:}

\begin{itemize}

\item Reduces search space.

\item Removes invalid values early.

\item Improves backtracking performance.

\end{itemize}



\subsection{Backtracking Search}


After AC-3 preprocessing, recursive Backtracking Search is used to find the
solution.


The process:

\begin{enumerate}

\item Select an unassigned variable.

\item Try a possible value.

\item Check constraint satisfaction.

\item Continue recursively.

\item Backtrack if contradiction occurs.

\end{enumerate}



\subsection{Minimum Remaining Values (MRV) Heuristic}


MRV is a variable selection heuristic.

It selects the variable with the smallest remaining domain.


Example:


\[
Cell A=\{1,2,3,4\}
\]


\[
Cell B=\{7\}
\]


MRV selects Cell B first.


\textbf{Benefits of MRV:}

\begin{itemize}

\item Reduces unnecessary branching.

\item Detects failure earlier.

\item Decreases node expansion.

\end{itemize}

\section{Object-Oriented Implementation}


The solver was implemented using an object-oriented approach.


The main class is:


\begin{verbatim}
SudokuCSP
\end{verbatim}


The class manages:


\begin{itemize}

\item Neighbor generation

\item Constraint checking

\item AC-3 execution

\item Backtracking search

\item Solution generation

\end{itemize}


This structure improves code organization and maintainability.

\section{Conclusion}


An intelligent Sudoku solver was successfully developed using Artificial
Intelligence techniques.


The Sudoku puzzle was modeled as a Constraint Satisfaction Problem and solved
using:


\begin{itemize}

\item CSP representation

\item AC-3 constraint propagation

\item Backtracking Search

\item MRV heuristic

\end{itemize}


The experimental results show that MRV significantly improves performance by
reducing unnecessary node expansion and execution time.
